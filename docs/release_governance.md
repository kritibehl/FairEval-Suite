# Release Governance

## Governance Workflow

Dataset Version
        ↓
Baseline Model
        ↓
Candidate Model
        ↓
Evaluation Runs
        ↓
Regression Analysis
        ↓
Human Review
        ↓
Release Board
        ↓
PASS / REVIEW / BLOCK

## Inputs

- groundedness scores
- hallucination metrics
- Responsible AI review
- latency thresholds
- cost thresholds
- evaluator agreement

## Outputs

- approved
- blocked
- rolled back
- needs review
